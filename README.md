# UW C++ Course

Solutions to seven C++ course assignments. Each project README contains a
shortened English summary of the original Polish problem statement, focusing
on the task and its main requirements.

| Project | Task |
| --- | --- |
| [1. Mastermind](project_1/README.md) | Play an interactive code-breaking game as either the codemaker or the codebreaker. |
| [2. Named Poset Collections](project_2/README.md) | Manage named partially ordered sets through an interface usable from C and C++. |
| [3. Fruit Picking](project_3/README.md) | Model fruit collection, interactions between fruits, and rankings of pickers. |
| [4. Invoke For All](project_4/README.md) | Extend `std::invoke` to calls over corresponding elements of tuple-like arguments. |
| [5. Playlists](project_5/README.md) | Build a playlist container with copy-on-write storage and strong exception safety. |
| [6. Text Moths](project_6/README.md) | Simulate moths consuming text using object-oriented design and C++ modules. |
| [7. Event Streams](project_7/README.md) | Compose stateful event streams with functional transformations and memoization. |
